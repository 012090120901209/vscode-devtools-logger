## 👋 Welcome to VS Code DevTools Logger!

I created this tool because I was **tired of copy-pasting console errors to ChatGPT** every 5 minutes while debugging. Sound familiar? 😅

### 🤖 The Problem
When debugging with AI assistants (ChatGPT, Claude, Copilot), you're constantly:
- Copy-pasting error messages
- Losing context between sessions  
- Missing important warnings that came before the error
- Manually piecing together the debugging story

### ✨ The Solution
**Let AI read your entire console log directly!**

This tool captures ALL VS Code DevTools Console output to a timestamped file. Now you can tell your AI assistant: *"Here's my complete log - analyze it and find the patterns."*

---

## 🚀 Quick Start (60 Seconds)

1. Clone this repo
2. Run: `$env:ELECTRON_ENABLE_LOGGING = "true"; code .` (or Mac/Linux equivalent)
3. Press `Ctrl+Shift+B`
4. Check `logs/console_capture.log` - share it with AI!

✅ **Works on Windows, macOS, and Linux**

## 🎯 Example AI Workflow

**Before this tool:**
```
You: *copies single error*
AI: "Can you show me the warnings before this error?"
You: *scrolls back, copies more*
AI: "What about the extension activation log?"
You: *searches, copies*
😫 Repeat forever...
```

**With this tool:**
```
You: "Here's my complete console log. What's causing these duplicate rules errors?"
AI: *analyzes entire log* "I see the pattern - your config loads twice because..."
😎 Done in one shot!
```

# 🎉 Welcome to VS Code DevTools Logger! Share Your Experience & Give Feedback

## 👋 Hello Developers!

Welcome to **VS Code DevTools Logger** - the first console logging tool designed specifically for **AI-assisted development**!

## 🤖 What Makes This Tool Different?

If you've ever found yourself:
- 📋 Copy-pasting console errors to ChatGPT over and over
- 🔄 Losing context when debugging with AI assistants
- 😫 Wishing GitHub Copilot could see your full error logs
- 🚫 Frustrated by incomplete error messages in AI conversations

**This tool solves that!** It captures ALL your VS Code console output to a file that your AI assistant can read directly.

## ✨ Why I Created This

I was debugging a VS Code extension and got tired of constantly copying error messages to ChatGPT. I wanted my AI assistant to see the **complete picture** - all the warnings, errors, and context - not just the snippet I remembered to copy.

So I built this tool. Now my AI debugging sessions are:
- ⚡ Faster (no copy-pasting)
- 🎯 More accurate (AI sees full context)
- 🧠 Smarter (AI spots patterns I miss)

## 🚀 Try It Out!

### Quick Start (3 Steps):
1. **Download** the files from this repo
2. **Launch VS Code** with: `$env:ELECTRON_ENABLE_LOGGING = "true"; code .` (Windows) or `export ELECTRON_ENABLE_LOGGING=1 && code .` (Mac/Linux)
3. **Press** `Ctrl+Shift+B` to start logging

Your console output is now saved to `logs/console_capture.log` - ready for AI analysis!
